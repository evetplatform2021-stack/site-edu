Оптимизация на Производителността, Profiling & JIT Компилация

Измерване и откриване на тесни места (Bottlenecks), профилиране на CPU и памет, векторизация, JIT компилация с Numba и ускорение чрез алтернативни среди.

9.1. Профилиране на Изпълнението с `cProfile` и `pstats`

Първата стъпка при оптимизация е измерването — "Premature optimization is the root of all evil". Модулът cProfile мери общото време и броя извиквания за всяка функция с минимален overhead.

profile_demo.py
import cProfile
import pstats

def heavy_function():
    data = [x ** 2 for x in range(1_000_000)]
    return sum(data)

# Стартиране на профилера
profiler = cProfile.Profile()
profiler.enable()

heavy_function()

profiler.disable()

# Сортиране и отпечатване на статистиката
stats = pstats.Stats(profiler).sort_stats('cumulative')
stats.print_stats(10)

9.2. Анализ Ред по Ред с `line_profiler`

Когато cProfile покаже критичната функция, line_profiler позволява микро-анализ на точното време, изразходвано на всеки отделен ред от изходния код.

line_profile_example.py
# Стартира се през терминала: kernprof -l -v script.py

@profile
def slow_matrix_operation():
    matrix = [[i * j for j in range(1000)] for i in range(1000)]
    total = 0
    for row in matrix:
        total += sum(row)  # Показва точно колко % от времето отива тук
    return total

9.3. Профилиране на Заделената Памет с `tracemalloc`

Стандартният модул tracemalloc проследява блоковете памет, заделени от CPython, и точното място в кода, където са били алокирани.

memory_trace.py
import tracemalloc

tracemalloc.start()

# Извършване на операции с паметта
large_list = [dict(a=i, b=str(i)) for i in range(100_000)]

snapshot = tracemalloc.take_snapshot()
top_stats = snapshot.statistics('lineno')

print("[ Top 3 Allocation Hotspots ]")
for stat in top_stats[:3]:
    print(stat)

9.4. Векторизация и SIMD Инструкции с NumPy

Стандартните Python списъци съхраняват указатели към разпръснати в RAM обекти. NumPy съхранява данните в последователни C масиви, трансформирайки Python итерациите във векторизирани CPU SIMD (Single Instruction, Multiple Data) инструкции.

vectorization_benchmark.py
import numpy as np
import time

size = 10_000_000

# 1. Традиционен Python списък (бавна итерация)
py_list = list(range(size))
t0 = time.time()
py_result = [x * 2.5 for x in py_list]
t1 = time.time()
print(f"Python list: {t1 - t0:.4f} sec")

# 2. NumPy векторизация (C скорост)
np_arr = np.arange(size)
t0 = time.time()
np_result = np_arr * 2.5
t1 = time.time()
print(f"NumPy vector: {t1 - t0:.4f} sec")  # 50x - 100x по-бързо!

9.5. JIT Компилация с Numba (`@njit`)

Numba трансформира чист Python и NumPy код в машинен код по време на изпълнение (Just-In-Time компилация) с помощта на компилаторната инфраструктура LLVM.

numba_demo.py
from numba import njit
import numpy as np

# @njit (nopython mode) форсира Numba да компилира без намесата на CPython interpreter
@njit
def monte_carlo_pi(nsamples: int) -> float:
    acc = 0
    for i in range(nsamples):
        x = np.random.random()
        y = np.random.random()
        if (x**2 + y**2) < 1.0:
            acc += 1
    return 4.0 * acc / nsamples

# Първото извикване тригерира JIT компилация, следващите са с C-скорост!
pi = monte_carlo_pi(10_000_000)
print("Pi:", pi)

9.7. Откриване на Memory Leaks (Изтичане на Памет)

Изтичането на памет в Python най-често се дължи на глобални речници, които пазят референции към неизползвани обекти, циклично цитиране с custom __del__ събития, или C extensions без `Py_DECREF`.

9.8. Практически Казус: Оптимизиране на Real-Time Pipeline ($100\times$ Ускорение)

Трансформиране на бавна обработка на финансови данни от чист Python до оптимизиран Numba/NumPy стрийм.

pipeline_optimization.py
import numpy as np
from numba import njit

# Неоптимизиран подход: O(N) Python итерация
def python_ema(prices, alpha=0.1):
    ema = [prices[0]]
    for p in prices[1:]:
        ema.append(alpha * p + (1 - alpha) * ema[-1])
    return ema

# Оптимизиран JIT подход: Без заделяне на излишни Python обекти
@njit
def fast_ema(prices, alpha=0.1):
    n = len(prices)
    out = np.empty(n, dtype=np.float64)
    out[0] = prices[0]
    for i in range(1, n):
        out[i] = alpha * prices[i] + (1 - alpha) * out[i-1]
    return out
